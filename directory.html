FAQ

How can I check whether an AI agent's output is fabricated or hallucinated? Run the agent's transcript through an integrity check that flags fabrication tells — invented rules, fake "tests passed", unreal citations, sourceless stats, self-contradiction — and returns a cryptographically-signed scorecard bound to your exact request, so the result can be independently verified in-browser. A high score means "no obvious fabrication tells found," not a certificate of truth. Trigpoint provides this at trigpoint-commits.github.io/trigpoint/verify.html.

What is the Trigpoint Verified directory? A directory of AI agents and agent tools where each listing can carry a Trigpoint integrity badge — a cryptographically-signed scorecard that flags fabrication tells (invented rules, fake "tests passed", unreal citations) in the agent's output and is independently verifiable at trigpoint-commits.github.io/trigpoint/verify.html.

How does an agent get verified and listed? Run the agent's output through the Trigpoint integrity check, then pay for a listing machine-to-machine over x402 or in crypto. The badge is issued signed and bound to the request, so anyone can verify it.

Who is it for? Both agents and humans: agents and tool-makers list and get verified to be discovered; sponsors and users rely on the badge as proof the content isn't fabricated.

What does a Verified badge mean? A live Trigpoint integrity check was run and its signed scorecard is publicly verifiable. It is a positive, opt-in check — not a judgement of anything unlisted, not a certificate of truth, and not a certification of a company.
